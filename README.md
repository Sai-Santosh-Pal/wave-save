# 🌊 Wave Save

**Wave Save** is a retro-style 8-bit arcade game built using Python and Pygame, where players protect the beach from incoming waves and falling debris. With pixel-perfect art, retro sounds, and scaling difficulty, it's designed to be fast-paced, addictive, and nostalgic.

---

## 🚀 How to Play

- **🕹️ Move Left/Right:** Arrow keys / A-D keys  
- **🛡️ Block Waves:** Position the character in front of incoming waves  
- **🎯 Avoid Hazards:** Don’t let debris hit you  
- **🔥 Powerups:** Collect items for temporary boosts  
- **💯 Score:** Survive as long as possible to increase your score

---

## 🎮 Features

- 8-bit pixel art & parallax scrolling backgrounds  
- Progressive difficulty scaling with time  
- Collision detection with physics  
- Powerups and collectibles  
- Background music & retro sound effects  
- Game over and high score tracking
