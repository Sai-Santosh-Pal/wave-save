# Wave Save 🏄‍♂️

A retro-style surfing game where you navigate through obstacles, battle pirates, and survive increasingly challenging waves!

## 🎮 How to Play

### Quick Start
1. Download `WaveSave.exe` from the latest release
2. Double-click to run the game
3. No installation required!

### Controls
- **SPACE** - Jump over obstacles
- **X** - Shoot waves at pirates
- **ESC** - Return to menu
- **R** - Restart game (when game over)

### Gameplay
- Surf through the waves and avoid obstacles like sharks and rocks
- Shoot waves at pirates to earn bonus points (50 points per pirate)
- Stay on waves to survive longer
- The game gets progressively harder with:
  - Increased scroll speed
  - Decreased gaps between obstacles
  - Weather changes at level 2 (rain effects)

### Scoring
- Score increases as you survive longer
- Bonus points for defeating pirates
- Try to beat your high score!

## 🔧 Development Setup

If you want to run the game from source:

1. Install Python 3.12 or later
2. Install required packages:
   ```bash
   pip install pygame==2.5.2
   ```
3. Run the game:
   ```bash
   python app/main.py
   ```
